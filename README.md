# Bipolar Disorder Simulation using GNN + RL + Lithium

## Overview
This project models bipolar disorder as unstable neural dynamics in a graph neural network.

Lithium treatment is simulated as a stabilizing control signal modulated by:
- Reinforcement learning (adaptive dosing)
- Circadian rhythm (time-dependent effectiveness)

## Components
- GNN → brain network
- RL → adaptive lithium policy
- Circadian → biological rhythm

## Key Idea
Bipolar disorder = high variance neural activity  
Lithium = control system minimizing variance
